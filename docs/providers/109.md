## 実装境界

109シネマズadapterは公開Web UIの通常操作だけを対象にします。

やらないこと:

- private/internal application endpointへ依存する
- provider-wide schedule/seat inventoryを収集する
- 複数上映回でseat holdを作って比較する
- anti-bot/CAPTCHA/MFA等を回避する
- auth/payment secretをMCPに保持させる

## Read Adapter確認項目

1. 劇場選択の現行UIを確認
2. 日付/作品/上映回のsemantic structureを確認
3. IMAX等のformat labelを正規化
4. availability表示があればvisible UIから意味を確認
5. current source URLを返す
6. candidate list変更時にexpected label mismatchで停止

## Seat Map確認項目

- seat map表示と仮押さえ開始タイミング
- row/seat labelのstable identification
- available/unavailable/special seatのsemantic
- adjacent seat計算をclick前に行えるか
- userが選んだ1組だけをselectする

## Checkout / Purchase確認項目

Checkout preparation前:

- 券種選択と会員状態の分岐確認
- login/CAPTCHA/本人確認はHuman Handoff
- payment credentialはMCPで扱わない
- transaction summaryをvisible UIから確認

Final purchase前:

- 現行規約/サイトポリシーを再確認
- exact final actionを一意に特定
- confirmation TTL / one-shot / context binding
- timeout/disconnect後の自動retry禁止
- success/failure/unknownを明示的に分類

## 方針

109固有の座席仮押さえ・購入フローを確認するまでは、seat selection以降のcapabilityを無効のまま維持します。
