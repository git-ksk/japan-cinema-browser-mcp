# Support

This project is maintained as an open-source project without a guaranteed support SLA.

- Reproducible bugs: use the **Bug report** issue form.
- Bounded feature proposals: use the **Feature request** issue form.
- Security vulnerabilities: use **GitHub Private Vulnerability Reporting**; do not post details publicly.
- Provider-site account, ticket, payment, refund, or theater-service questions: contact the cinema provider directly. This repository is not affiliated with TOHO Cinemas, AEON Cinema, 109 Cinemas, or their operators.

Before opening an issue, review `README.md`, `COMPLIANCE.md`, `docs/SECURITY.md`, and the relevant provider document under `docs/providers/`.
